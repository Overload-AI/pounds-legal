# POUNDS — legal documents

Published Privacy Policy and Terms of Use for the POUNDS iOS app, by Give Me Pounds LLC.

- https://overload-ai.github.io/pounds-legal/privacy
- https://overload-ai.github.io/pounds-legal/terms

## ⛔ Do not hand-edit these files

They are **generated** from `Planning/legal/*.md` in the main POUNDS repository by
`site/legal/build.mjs`. Editing the HTML here creates a second copy of a binding contract that
disagrees with the reviewed one — which is exactly the failure that produced a duplicate terms
document with no arbitration clause, and a privacy manifest that agreed with its registry while
both were wrong.

Change the source, rebuild, republish.

## Effective version

These correspond to `policy_versions.version` in the POUNDS database. The consent gate compares the
version a user accepted against the current one, so **publishing materially changed text requires a
new version row**, not an edit in place.
